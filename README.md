# AI-Powered Customer Churn Intelligence System

An end-to-end Machine Learning and Generative AI project
to predict customer churn and recommend retention strategies.

## Features
- Customer churn prediction
- SHAP-based explanations
- Personalized AI retention recommendations
- SQL-based customer analytics
- Interactive Streamlit dashboard
- Power BI business insights

## Tech Stack
Python, SQL, Scikit-learn, XGBoost, SHAP,
Gemini API, Streamlit, Power BI
